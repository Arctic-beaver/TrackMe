# TrackMe — контракт локализации

**Статус:** принято для Этапа 1  
**Поддерживаемые языки:** русский, английский, испанский  
**Область:** renderer, Electron main process, accessibility и форматирование

## 1. Цель

Локализация создаётся вместе с первым компонентом. Ни один экран не считается
готовым, если его пользовательский текст нельзя показать на `ru`, `en` и `es`.

Поддержка языка не должна:

- менять пользовательские данные;
- проникать в доменную модель;
- требовать перезапуска при явном переключении;
- зависеть от сети или внешнего сервиса переводов.

## 2. Locale

```ts
type ResolvedInterfaceLocale = 'ru' | 'en' | 'es'
type InterfaceLocale = 'system' | ResolvedInterfaceLocale
```

`system` — режим автоматического выбора, а не четвёртый язык:

- `ru`, `ru-*` и `ru_*` → `ru`;
- `es`, `es-*` и `es_*` → `es`;
- всё остальное → `en`.

В настройках хранится `InterfaceLocale`. Вычисленное значение при `system` не
сохраняется и определяется при запуске заново.

## 3. Размещение кода

Паттерн локализации переносится из Yinkie в собственный код TrackMe:

```text
src/shared/localization/
  catalogs.ts
  index.ts
src/renderer/src/localization/
  LocalizationProvider.tsx
  localizationContext.ts
  useLocalization.ts
scripts/
  i18n-policy.mjs
```

Общий модуль не зависит от React и доступен renderer и main process. Для MVP не
добавляется отдельная runtime-библиотека локализации.

## 4. Каталоги и ключи

Английский каталог является эталоном типов и безопасным fallback:

```ts
export const englishCatalog = {
	'navigation.today': 'Today',
	'task.status.todo': 'To do'
} as const

export type LocalizationKey = keyof typeof englishCatalog
```

Русский и испанский каталоги обязаны:

- содержать точно тот же набор ключей;
- использовать те же именованные параметры;
- иметь форму `other` для plural-сообщений;
- проходить compile-time и runtime-проверку parity.

Ключи описывают смысл, а не исходную фразу: `task.status.done`, а не
`text.done`. Предложения переводятся целиком. Запрещено собирать их из нескольких
переведённых фрагментов.

## 5. Форматирование

Для locale-aware значений используются встроенные API:

- `Intl.DateTimeFormat` — даты и время;
- `Intl.RelativeTimeFormat` — «через 2 дня»;
- `Intl.PluralRules` — формы количества;
- `Intl.ListFormat` — списки тегов и дней;
- `Intl.Collator` — отображаемая сортировка названий.

ISO-даты, локальные минуты, enum-коды статусов и правила повторений не содержат
переведённых строк. Неделя всегда начинается с понедельника согласно продуктовому
правилу TrackMe, независимо от locale.

## 6. Граница процессов

Application services и IPC возвращают стабильные коды и параметры:

```ts
{
  code: 'REVISION_CONFLICT',
  values: { taskName: 'Урок 14' }
}
```

Renderer переводит сообщения интерфейса. Main process использует тот же общий
каталог для меню, системного трея, диалогов и уведомлений. Готовые англоязычные
сообщения через IPC не передаются.

После смены языка:

- React обновляется через `LocalizationProvider`;
- `document.documentElement.lang` получает `ru`, `en` или `es`;
- Electron перестраивает меню и трей;
- новые уведомления используют выбранный язык;
- текущий экран, форма, фильтры и тема не сбрасываются.

Все три языка используют направление `ltr`.

## 7. Пользовательский контент

TrackMe не переводит:

- названия и описания задач;
- названия и описания проектов;
- пользовательские теги;
- введённые ссылки и заметки.

Этот контент хранится и показывается без изменения. Локализуются только подписи,
системные значения, даты, статусы и сообщения вокруг него.

## 8. Базовая терминология

| Смысл         | Русский    | English        | Español       |
| ------------- | ---------- | -------------- | ------------- |
| Today         | Сегодня    | Today          | Hoy           |
| Week          | Неделя     | Week           | Semana        |
| Month         | Месяц      | Month          | Mes           |
| Projects      | Проекты    | Projects       | Proyectos     |
| Create        | Создать    | Create         | Crear         |
| `todo`        | Входящие   | To do          | Pendientes    |
| `planned`     | На сегодня | Plan for today | Plan para hoy |
| `in_progress` | В процессе | In progress    | En curso      |
| `done`        | Готово     | Done           | Hecho         |

Названия продукта, девиз `Agile your life` и имена семейств тем не переводятся.

## 9. Quality gate

Команда `i18n:audit` анализирует TSX и запрещает непереведённые литералы в:

- JSX-тексте;
- `aria-label`, `aria-description`, `alt`, `title` и `placeholder`;
- пользовательских строковых выражениях.

Автоматические тесты проверяют:

1. точное совпадение ключей трёх каталогов;
2. совпадение именованных параметров;
3. plural rules для `ru`, `en` и `es`;
4. форматирование дат и относительных сроков;
5. fallback системного locale;
6. обновление renderer, меню, трея и уведомлений;
7. отсутствие обрезки длинных испанских строк на поддерживаемых ширинах.

## 10. Definition of done для UI

Экран или компонент готов, когда:

- весь пользовательский текст приходит из каталога;
- `ru`, `en` и `es` отображаются без перезапуска;
- даты и количества форматируются через общий слой;
- пользовательские данные не меняются при смене языка;
- длинная испанская версия не перекрывает соседние элементы;
- клавиатурная навигация и accessibility labels работают на всех трёх языках;
- `i18n:audit`, parity-тесты и typecheck проходят.
